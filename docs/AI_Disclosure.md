# AI / SI Usage Disclosure
AI tools (Claude by Anthropic) were used to assist in writing the route-planning code (terrain cost grid, A* path search, re-routing, API and web game) and in reviewing the data-analysis notebook. All terrain data comes from real NASA/USGS sources (MRO CTX DTMs via the USGS Astrogeology STAC catalog, and CTX imagery from NASA Mars Trek). Maps and figures in the project were produced by our own code from this data, not generated by AI. Concept illustrations and the explainer video used in internal team discussion were AI-assisted and are not part of the submitted results. All AI-assisted code was reviewed, run and tested by the team.
